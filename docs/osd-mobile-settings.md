# Мобильные настройки OSD

Обновление 0.1.5: добавлен ручной `translationEnabled`, default OFF. TV-меню
управляется кнопкой OK пульта; телефон меняет тот же флаг. Автоматический запуск
по HDMI/приложениям и русскому языку отменён. См. `manual-translation-control.md`.

Основной вид — **«Пульт»**: крупные элементы и вкладки «Заливка», «Буквы»,
«Перевод». Два альтернативных вида доступны только в демонстрации `?preview=1`.
Демонстрация меняет пример внутри страницы и не отправляет настройки на ТВ.

## Подключение

После установки контроллер OSD поднимает HTTP-сервер на IPv4 LAN-адресе ТВ,
порт **18780**. Меню ТВ «Подключить телефон» получает QR-код и одноразовый
шестизначный PIN через loopback catalogue port 18779. QR содержит только URL.
Телефон должен быть в одной локальной сети с телевизором.

PIN действует 5 минут. Пять неверных попыток блокируют ввод на 30 секунд и
аннулируют PIN. Регистрация выдаёт HttpOnly/SameSite=Strict cookie на 8 часов;
перезапуск контроллера аннулирует сессии. Настройки сохраняются отдельно от
сессий и переживают перезапуск. Используется обычный HTTP домашней сети;
шифрование транспорта не реализовано.

Запросы изменения проверяют Origin/Host, частный адрес клиента, JSON,
размер тела и зарегистрированную сессию. Создание PIN разрешает только
установленное TV-меню с отдельной capability, сгенерированной при установке.
Значения PIN, cookies и capability не пишутся в журнал и не входят в Git.

## Настройки и исполнение

Файл `/media/developer/game-translator-layers.json` остаётся единственным
источником параметров оформления; существующий watcher читает его каждые
250 мс и обновляет фоновый OSD. Новый сервер не запускает захват кадров.

- Включение заливки и текста.
- Запас заливки 0–16 **пикселей OSD**, исходное значение 2.
- Цвет фона: из игры либо заданный `#RRGGBB`, непрозрачность 0–100%.
- Цвет текста: из игры либо заданный `#RRGGBB`.
- Высота и ширина текста независимо, 50–200% от автоматического размера.
  Масштабируется содержимое текста, а не геометрия заливки/контейнера.
- Правило `normal` / `all`: описания и реплики либо также однословные подписи
  и названия. OCR-порог качества не меняется. Озвучка недоступна; включить
  её через API невозможно.

`FrameClient` отправляет выбранное правило в `X-PP-OCR-Policy`; Orange
применяет его одинаково к ранним событиям и итоговым областям. Меняется только
допуск перевода, не detector, распознавание, quads, кадр или модель.
Изменение правила инвалидирует admission epoch на ТВ, чтобы результаты старой
сессии не попали в OSD. Обычные изменения оформления не сбрасывают наблюдения.

## Установка

1. Установить `com.serjio193.lggametranslator.settings_0.1.5_all.ipk`.
2. Распаковать `mobile-osd-controller-0.1.5.tar.gz` на ТВ.
3. Выполнить `sh install-mobile.sh <директория распаковки>`.

Установщик сохраняет резервные копии, добавляет renderer dependency
`manual-style.js`, генерирует pairing capability и переиспользует предыдущий
installer для перезапуска контроллера/relay. Установленный
`translation-watcher.js` и PicCap не заменяются. Повторная установка IPK
требует повторного запуска installer, восстанавливающего device capability.

## Переводчик и расход Google

Во вкладке «Перевод» добавлен выбор Google / локального Bergamot+MADLAD,
месячный счётчик отправленных символов, полоса расхода и остаток до 490 000.
Значения обновляются каждые 3 секунды. Аналогичный блок есть в меню ТВ.
Это расход нашей системы, не показания Google Billing. Неопределённые/ошибочные
сетевые попытки остаются учтёнными; попадания в кэш не расходуют символы.
Настройки источника сохраняются на Orange, существующий контроллер ТВ
подхватывает их и инвалидирует ответы прежнего источника.

API-ключ можно ввести на ТВ: loopback Node шифрует его до LAN-отправки.
На обычной HTTP-странице телефона ввод ключа отключён. После настройки ключа
телефон может переключать переводчики. Сервер никогда не возвращает ключ.
Подробности, provisioning и границы проверки: `google-budget-osd.md`.
